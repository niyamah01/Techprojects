1 Project Overview

This is a microcontroller-based electronic voting system built with ESP32 and OLED display. It supports secret ballot voting for 3 candidates, configurable maximum voters, countdown timer, majority winner detection, and a clean user interface.

Secret Voting

Live candidate results are hidden during voting. Only total votes are shown.

Configurable

Set Max Voters (1-50) and Voting Time (10-300s) before starting.

Majority Detection

Automatically checks if the winner has more than 50% of total votes.

Dual Closing

Voting closes when timer ends or maximum voter limit is reached.

3 State: Welcome Page STATE_WELCOME

Shown immediately after power-on or reset.

  • Displays project title and university name
  • Automatically moves to Setup Mode after 2.5 seconds
  • Or moves immediately if any button is pressed

4 State: Setup Mode STATE_SETUP

User configures the election parameters before voting starts.

Configurable Parameters

Parameter Range Default Step
Max Voters 1 – 50 10 ±1
Voting Time 10 – 300 seconds 60 seconds ±5 seconds

Button Controls in Setup

Button Action
C1 Decrease the currently selected value
C2 Switch between Max Voters ↔ Voting Time
C3 Increase the currently selected value
RESULT Confirm settings and Start Voting
RESET Load default values (10 voters, 60 seconds)

5 State: Voting Mode STATE_VOTING

Secret ballot style – individual candidate votes are not shown live.

What is shown on screen

  • Large remaining time countdown
  • Total votes cast so far (e.g. Votes Cast: 4/10)
  • Status: OPEN or CLOSED

Button Controls during Voting

Button Action
C1 Cast vote for Candidate 1
C2 Cast vote for Candidate 2
C3 Cast vote for Candidate 3
RESULT Show final election Result
RESET Return to Setup Mode (clears all votes)
Voting automatically closes when:
• Countdown timer reaches 0 OR
• Maximum number of voters is reached

After every successful vote, a “Thank You” confirmation screen is shown briefly.

6 State: Result Screen STATE_RESULT

Displayed when the user presses the RESULT button.

Possible Outcomes

Situation Display
No votes cast “NO VOTES – Yet recorded”
Two or more candidates have equal highest votes “TIE!” + vote list of all candidates
Clear winner with > 50% votes MAJORITY WINNER + big candidate number + all votes
Highest votes but ≤ 50% WINNER (No Majority) + big candidate number + all votes

8 Software Stack

  • Platform: PlatformIO
  • Framework: Arduino
  • Board: ESP32 Dev Module
  • Libraries: Adafruit GFX + Adafruit SSD1306
  • Display: 128×64 OLED (SSD1306) via I2C
